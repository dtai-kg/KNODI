KNODI

Knowledge-based support for complex data analysis in multi-stage manufacturing

About the project Research

About KNODI

Modern manufacturing companies gather vast data from their manufacturing processes using Industrial Internet of Things (IIoT) technologies. However, creating value from this data remains a struggle as production processes involve many interrelated steps with variability in products, processes, and context. Data from different sources like production planning, sensors, and operator records must be combined. For example, today at Bekaert, a team of several experienced data scientists and domain experts works 3 to 6 months to solve a single business question, such as: "What factors determine the energy consumption for this specific product?"

In KNODI, Bekaert, Materialise, Delaware, and researchers from Flanders Make and KU Leuven research how state-of-the-art language-processing AI, combined with structured knowledge representations, can be deployed to extract, store, and use company knowledge to perform industrial, complex production data analyses in energy consumption and root cause product quality analysis. The aim is for in-house data consumers to leverage this knowledge to explore a rich data context and answer complex questions more efficiently. Reducing the effort to answer complex questions is the key to reduce energy consumption, improve efficiency, or eliminate scrap.

Objective

The goal of KNODI is to research how modern large language models can be combined with an enterprise knowledge graph to store structured knowledge in the context of complex data analysis. The resulting framework for data analysis allows non-data experts to efficiently address unstructured data (product manufacturing information, expert knowledge, models, …) and semi-structured data (sensor measurements, log files, …) in a reliable manner for solving complex questions related to the production process. The aim of combining large language models (LLMs) with an explicit knowledge representation is to create an analysis support framework with a level of reliability, transparency, and flexibility that pure state-of-the-art language models, trained directly on the same data, would not be able to reach.

Research

KNODI's research is organised in the following lines of work.

  1. 1

    LLM-supported ingestion of unstructured data in the knowledge graph.

    Compare LLM workflows for interpreting unstructured manufacturing data (PMI documents) and generating structured knowledge from these documents.

  2. 2

    LLM-supported data mapping.

    Use LLMs for mapping semi-structured data sources (i.e., ERP, MES, and sensor data) to a structured knowledge representation.

  3. 3

    Effective data analysis using Knowledge-based Digital Twin.

    Research how LLMs can be used to query structured knowledge and how to frame this in an effective data science and non-data expert analysis approach.

  4. 4

    System architecture, validation and dissemination.

    The project partners set requirements and use case scenarios and define a reference system architecture for the data analysis framework, which is validated on a generic research demonstrator case and two industrial use cases from Bekaert and Materialise.

Use cases

Next to a generic research demonstrator, the KNODI framework will be validated on two industrial use cases.

  • Bekaert.

    Production data analysis in steel wire manufacturing.

  • Materialise.

    Production data analysis in additive manufacturing.
